# POOF! 三声清盘

二维回声消除益智游戏，包含完整 **20 关**。点空格吹气，让同色角色碰撞消失，三声内清空棋盘。

**[在线试玩](https://qml780.github.io/poof-three-puffs/?level=1)** · **[下载单文件 HTML](https://github.com/qml780/poof-three-puffs/raw/refs/heads/main/index.html)**

## 怎么玩

1. 点击空格，气浪沿上、右、下、左四个方向传播，最多探测三格，推动遇到的角色向外一格。
2. 推动的角色撞上同色角色，两只一起消失，气浪可继续穿过空位；异色、石柱和边界会阻挡推动。
3. 从第二次点击开始，先执行新气浪，再从上一次点击的位置补一阵回声。
4. 每次有效点击消耗一声，包括空吹。每关最多三声，全部清空即通关。可随时撤销、重来或查看下一步提示。

关卡固定，没有随机补充角色或自动洗牌。第 13–20 关强调配对顺序、借位挡风和新旧气浪的配合。

主界面采用精简布局：直接展示棋盘和操作按钮，选关默认收起。规则通过“怎么玩”查看，详细提示只在点击“下一步”时出现。

## 运行

下载仓库后，用浏览器打开根目录的 `index.html` 即可游玩。图形、音效、代码和关卡全部内置，无需安装依赖或连接素材服务。

手机优先使用在线试玩地址。微信、QQ 的**附件预览可能不执行 JavaScript**；如果看到“游戏尚未运行”，请用支持脚本的浏览器打开文件，或打开在线链接。无法保证所有手机附件预览器运行游戏。

成绩存储在当前浏览器；不同设备、浏览器和网站地址之间不自动同步。禁用存储时仍可游玩，但可能无法保存成绩。

需要本地 HTTP 服务时，安装 Node.js 18 或更新版本，在项目目录运行：

```sh
npm start
```

然后打开 `http://127.0.0.1:4176/`。修改端口可运行 `node server.cjs 4180`。

## 修改与检查

`src/` 保存可读的手机兼容源码；构建不需要第三方依赖：

```sh
npm run build
npm test
```

- `src/engine.js`：确定性的推动、碰撞、回声和求解器。
- `src/levels.js`：20 关布局、通关路线及提示。源码内包含解法，请注意剧透。
- `src/game.js`：点击交互、动画、提示、撤销和成绩。
- `src/compat.js`：旧浏览器基础兼容处理。
- `src/style.css`、`src/template.html`：界面样式和单文件模板。
- `scripts/build.cjs`：将所有资源内联到根目录 `index.html`。

测试覆盖 20 关通关路线和最短步数、三声限制、终盘十二只连消，以及 HTML 与源码的一致性。移动端曾做缺失接口和禁用存储的兼容性模拟，未覆盖全部手机真机。
